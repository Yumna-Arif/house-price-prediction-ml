# House Price Prediction using Machine Learning

## Project Overview
This project focuses on predicting house prices using the King County House Sales dataset (USA). It explores the relationship between different house features and their selling prices using Python and Machine Learning regression techniques.

## Objectives
- Explore and understand the housing dataset.
- Analyze relationships between house features and prices.
- Visualize data using graphs and statistical techniques.
- Build and evaluate regression models for house price prediction.

## Technologies & Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Machine Learning Techniques
- Simple Linear Regression
- Multiple Linear Regression
- Polynomial Regression
- Ridge Regression
- Standard Scaling
- Model evaluation using R-squared (R²)

## Project Workflow
1. Load and explore the dataset.
2. Perform statistical analysis and data visualization.
3. Identify relationships between features and house prices.
4. Train regression models.
5. Apply polynomial feature transformation and Ridge Regression.
6. Evaluate model performance using R² scores.

## Dataset
**King County House Sales Dataset (USA)**

The dataset contains information about house sales in King County, including bedrooms, bathrooms, living area, floors, waterfront status, and selling prices.

## Project File
